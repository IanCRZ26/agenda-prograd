# Agenda Integrada - PROGRAD / UEA

Sistema institucional desenvolvido para centralizar, gerenciar e coordenar o calendário de eventos e atividades das coordenações da Pró-Reitoria de Graduação (PROGRAD) da Universidade do Estado do Amazonas (UEA). O objetivo principal é garantir que a PROGRAD tenha o controle total e centralizado de todas as datas programadas.

---

## 🚀 Funcionalidades

* **Controle Centralizado:** Visão macro da PROGRAD sobre os eventos planejados.
* **Autonomia para as Coordenações:** Cadastro e gerenciamento de datas de eventos específicos de cada setor.
* **Evita Conflitos:** Facilidade na identificação de choques de datas no calendário institucional.
